# 0003 — 旋转、尺寸和属性编辑的撤销／重做

**Date:** 2026-10-16
**Status:** Accepted (user approved; implemented)

## Problem

现有历史只捕获平移。圆半径、旋转矩形角度和尺寸等几何修改会清空已有历史，用户不能连续撤销移动、旋转、resize 和删除。

## Solution

保留原平移 API，增加独立的 ShapeGeometryState 和可嵌套的 ShapeVisualBase.BeginGeometryEdit 编辑范围。完整状态由图形实现捕获／恢复，包含所有会在已有旋转或 resize 交互中变化的模型参数和附加文字。编辑期间发送正常属性通知，但仓库延迟记录；最外层范围结束后比较前后状态，生成一步几何历史。范围内的 Translate 不再单独发布平移历史。

```mermaid
flowchart LR
    Input[手柄拖动 / 属性提交] --> Scope[BeginGeometryEdit]
    Scope --> Model[模型实时更新与通知]
    Model --> Final[MouseUp 完成 / 属性提交完成]
    Final --> Compare[比较完整前后状态]
    Compare --> History[画板 Undo / Redo]
```

画板在已有单图形编辑开始时开启几何范围，在 MouseUp 返回后结束（包含 DXF BakeTransform）；组合平移仍走现有事务。Esc、捕获丢失、卸载和更换仓库结束范围并保留已发生的编辑。属性面板一次实际提交开启一个范围，未修改和无效输入不入栈。

图形状态与显示变换保持现有职责：恢复模型、句柄、文字、导出数据，不改变图层、样式、身份、锁定及视觉 Transform。视口缩放不进历史。未适配的第三方模型编辑继续清空历史，保留自定义编辑能力。新增绘制、组整体旋转／缩放、组合／解组、图层分配及完整文档持久化不属于本次范围。

## Alternatives

- 逐个记录属性通知：通知不等于用户步骤，缺少旧值，且 DXF 鼠标释放会合并变换。
- 反向旋转／缩放：不能精确恢复浮点参数或完整导出状态。
- 直接扩大平移快照语义：会改变现有扩展契约；单独提供几何快照更明确。

## Acceptance

- 内置及现有扩展图形的 resize／旋转恢复完整参数；重复重放不累积误差。
- 一次拖动只产生一步，几何未变化时不产生记录也不清空 redo。
- 移动、旋转、resize、删除可按操作顺序连续撤销／重做。
- DXF MouseUp 合并变换后的显示和导出恢复一致。
- 属性面板端点、长度、位置和尺寸的一次提交形成一步；无效输入不产生记录。
- 原移动、删除、组关系、锁定／隐藏、缩放和手势中断测试保持通过。

无新依赖、外部服务或持久化变更。
