## 3. 功能一：批量选中与换层

### 3.1 用户操作

| 位置 | 操作 | 行为 |
| --- | --- | --- |
| 工具栏 | 点击“选择” | 通过绘制结束或取消流程进入选择模式 |
| 画布 | 单击图形 | 单选该图形 |
| 画布 | Ctrl 点击图形 | 加入或移出选择集合 |
| 画布 | 从空白处由左向右拖框 | 选择完全在框内的图形 |
| 画布 | 从空白处由右向左拖框 | 选择与框相交的图形 |
| 画布 | Ctrl 从空白处拖框 | 将框选结果追加到选择集合 |
| 画布 | 中键拖动 | 平移画布 |
| 图层树 | Ctrl 点击图形行 | 加入或移出选择集合 |
| 图层树 | Shift 点击图形行 | 选择锚点与当前行之间的可见图形行 |
| 图层行 | 点击“选择” | 选中该层中符合批量选择条件的图形 |
| 画布或图层树获得焦点时 | Ctrl+A / Esc | 全选符合条件的图形 / 清空选择 |
| 属性区域 | 选择所属图层，点击“应用到所选图形” | 将选择集合统一迁移到目标层 |

画布框选和整层选中纳入可见、已完成、未锁定的图形。锁定对象的单选查看遵循现有行为，换层前执行锁定校验。文字输入控件获得焦点时，由输入控件处理 Ctrl+A、Delete 等按键。

框选矩形和命中计算使用画布模型坐标，拖动阈值按屏幕距离计算。完全包含使用图形主体的边界，相交使用轮廓、线段或可见填充几何；空心图形的空白内部、句柄及文字标注不作为相交命中依据。自定义图形通过基类的选择几何扩展入口提供对应实现。

### 3.2 手势分工

实现前 `ImageViewerBasic` 在预览鼠标事件中优先捕获 Ctrl 左键，因此本次同时调整了查看器和画布的事件处理。

将查看器的平移条件收敛为中键，Ctrl 左键事件交给 `SketchBoard` 处理选择：

- 中键拖动执行平移，由查看器持有鼠标捕获。
- 选择模式下普通空白拖动执行框选，Ctrl 空白拖动执行追加框选，由画布持有鼠标捕获。
- Ctrl 点击图形切换选中状态，该次手势不触发图形拖拽。
- 绘制时 Shift 处理线条方向约束；图层树中的 Shift 点击处理范围选择。
- 鼠标释放、捕获丢失、模式切换时统一结束手势，避免残留框选或拖拽状态。

框选仍使用系统拖动阈值区分空白点击与拖框。原 Ctrl 平移测试调整为 Ctrl 左键不启动平移，并新增 Ctrl 点选和追加框选测试。

### 3.3 选择状态与显示

`IShapeRepository` 提供 `ReadOnlyObservableCollection<ShapeVisualBase> SelectedGeometries`，由仓库维护。画布、树和属性区域读取同一集合。

增加 `SetSelection(IEnumerable<ShapeVisualBase>)`，内部完成去重、有效性检查、选择状态转换和事件通知。输入中的图形必须属于当前画布且已完成、可见；校验失败时保持原选择集合。选择顺序决定活动图形。UI 的 Ctrl、Shift、框选操作计算目标集合后调用此接口。

保留 `SelectedGeometry` 作为活动图形：旧调用设置非空值时建立单选，设置 null 时清空选择；多选时指向最近加入的活动图形。旧的绘制流程设置未完成对象时保持原有用途，批量选择入口和换层接口执行完成性校验。`SelectedShape` 继续作为单选属性编辑的入口。

- 单选：显示图形属性及所属图层。
- 多选：显示“已选 N 个图形”和公共的换层操作；同层时显示层名，跨层时显示“混合图层”。
- 多选的画布反馈由选择轮廓表达，几何拖拽句柄在单选时提供。
- 图形删除或所属层隐藏后，仓库自动清理相应选择项；绘制状态和选择集合分别管理。
- 图层行的可见性复选框、编辑按钮仅执行各自操作，避免意外清空图形选择。

WPF `TreeView` 不提供原生多选，增加树选择行为，以仓库集合驱动图形行高亮。树自身的焦点和当前项用于键盘导航。

现有 Delete 入口统一使用仓库选择集合执行删除，并应用锁定和绘制状态校验；画布和树的处理结果一致。

### 3.4 批量迁移

增加 `AssignShapesToLayer(IEnumerable<ShapeVisualBase> shapes, ShapeLayer targetLayer)`，返回实际迁移数量。单个图形也通过这个接口完成换层。

迁移流程：

1. ViewModel 从图层管理器解析有效目标定义；仓库对输入去重并校验所有图形属于当前画布、已经绘制完成且未锁定。
2. 预备目标图层的画布独立副本和样式，保留样式工厂的扩展能力。
3. 一次提交所属层变更，保留图形 ID、几何数据、标签和对象实例；已属于目标层的图形计为无需迁移。
4. 合并缩放、画布重绘及树分组刷新，批量完成后发布汇总通知。
5. 目标层可见时保留选择；目标层隐藏时从可视集合及选择集合移除。应用按钮旁说明移入隐藏层后的可见性。

校验失败时整批操作失败，并显示原因；准备样式失败时撤回操作。提交阶段出现异常时恢复原有图层归属和选择状态，保证集合一致。

当前绘制图层与迁移目标共用内部的画布图层副本获取逻辑，按 `LayerId` 缓存。定义变更更新该画布的副本；不同画布各自计算缩放。

## 4. 功能二：图层新增、修改与保存

### 4.1 UI 入口

图层区域提供“新增”“保存”“另存为”，已有图层行保留“编辑”。显示保存路径及保存状态。

复用 `LayerEditorWindow`：

- 新增：从当前配置图层复制完整样式作为初值，填写新名称、说明和各状态样式；ID 由管理器生成。
- 修改：填写当前定义，ID 固定，名称和说明可修改。
- 样式状态：选择普通、鼠标悬停（Hover）、选中或锁定，分别设置线条/填充颜色、线型、线宽和填充不透明度。切换保留草稿，仅查看未配置状态时保留其普通样式回退行为。
- 应用：校验并提交定义，更新树、下拉框和已有图形。
- 取消：丢弃弹窗草稿。

新增成功后加入图层列表和树，并设为当前绘制图层。正在绘制的图形按现有绘制生命周期处理，新的当前图层用于下一次创建图形。

### 4.2 图层定义规则

- `LayerId` 在配置中唯一，由管理器分配；修改保持 ID 不变，因此重命名不改变图形归属。
- 名称去除首尾空白、不能为空；新增和重命名检查名称重复，比较时忽略大小写。
- 线宽为有限正数；填充透明度在 0 到 1 之间；颜色和线型必须有效。
- 新增包含 `Normal`、`Selected` 等完整状态配置；未编辑的状态保持原配置，编辑缺省的悬停或锁定状态时建立独立配置。
- 图层共享全局测量配置，使用已注入的样式工厂创建定义和副本。
- 加载时补充 ID 冲突及定义校验，避免树将重复 ID 合并成一层。

### 4.3 保存流程

保存复用现有 `LanShapesConfiguration` JSON 格式，保留测量设置、可用绘制工具和全部图层定义。

| 情况 | 行为 |
| --- | --- |
| 已经加载或保存过配置文件 | 新增、修改确认时保存到已知路径，成功后发布定义更新 |
| 没有配置路径 | 应用到内存并显示待保存状态；点击保存打开文件选择 |
| 点击保存 | 校验并保存当前定义，更新保存状态 |
| 点击另存为 | 选择新路径，成功后将其设为后续保存路径 |
| 取消文件选择 | 保留当前内存定义及待保存状态 |
| 写入失败 | 保留原文件和原保存路径，显示错误并保留可重试的编辑草稿 |

保存前构建候选配置并完成验证，在目标文件同目录写临时文件，成功后替换目标文件。保存路径、保存状态以及内存定义只在对应步骤成功后更新。

`IShapeLayerManager` 增加创建、修改定义的入口，继续提供 `SaveConfiguration`；ID 分配、名称校验、草稿提交、配置序列化和保存失败处理集中在该模块中。UI 负责展示文件选择和错误信息，ViewModel 连接操作与管理器。

图层定义变更发布通知，使用同一管理器的各查看器更新名称和样式副本；每个画布管理自己的缩放与可见性。

## 7. 同时保存图形及图层归属的扩展方案

若保存范围包含绘图，在阶段三前增加文档模型：每个图形记录稳定 ID、类型标识、几何数据、所属 `LayerId` 及需要恢复的图形状态；文档包含对应图层定义。

加载时先建立并校验图层，再按 `LayerId` 构造图形，使用当前画布的样式副本。缺失图层引用作为文档错误反馈。旧的仅几何数据通过明确的默认图层规则迁移。

关键验收是：多种图形跨层迁移后保存，清空画布并重新加载，每个图形的 ID、几何、所属层和样式均能恢复。这项工作需要覆盖各类 `IGeometryMetaData`，按独立步骤估算及验收。
